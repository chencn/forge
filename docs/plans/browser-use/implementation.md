## 当前交付

Windows 上已连通：原生 wry child / WebView2 → 当前用户专用 named pipe → 独立 stdio MCP companion → Forge 管理的 Codex / Claude。主窗口仍保留 Tauri `WebviewWindow` 身份。

打开 AI 总开关后，浏览器和 AI 截图默认启用；有所属会话的新页面默认允许 AI 操作。上传工作区文件和任意脚本默认关闭，须用户在设置中分别手动授权。已有明确关闭的设置继续保留。CLI 在每轮启动时自动注入 `forge_browser`，页面按需创建。浏览器统一从侧边活动栏进入，默认打开右侧浏览器工具窗口；AI 新建页只展开侧栏，不切换当前代码 / AI 编辑器标签。宽度独立可调，也能按活动栏既有机制移动到左侧。展开浏览器时占满编辑区，保留两侧活动栏和另一侧已打开的工具面板；还原后恢复此前宽度，收起浏览器或切换工具时结束展开状态。

## 权限和生命周期

- 随机 token 绑定本应用实例、规范化工作区、会话、run；工具参数不能指定另一个身份。结束、停止或关闭 AI 后失效。
- Read / Plan 由宿主限制；不依赖 CLI 的 allowedTools 或提示词。目标页关闭后报错，不切换到 UI 当前页。
- AI 页使用 workspace + session 的 managed profile。用户手动页使用单独的 human profile；有会话的新页在导航前授予 Control，无会话页保持 None。同会话 AI 新建页无法继承用户页登录 cookie。用户地址栏导航保留所选权限并重新绑定目标 origin，明确设为 None 的页面继续私有；网页自行跨站撤权。同站历史与刷新取消在途请求而保留权限，“停止”立即撤权。
- 用户页共享只授当前 origin；跨站导航撤权并清除旧观察。UI 开页和选页不修改 AI 的 workingTabId。
- 每页异步串行队列；派发前、UI 线程执行时和返回观察前校验授权及代际。请求总期限阻止超时队列晚到后继续派发。
- 页面无 Tauri IPC、自定义本地协议或宿主对象；页面权限请求、下载和新窗口默认阻止。
- 额外授权变更会使旧 ticket / refs 失效，保留本轮 token；关闭浏览器或 AI 则撤销 token 和页面授权。
- native / COM 对象只在 UI 线程。后台 broker 不持状态锁等待 UI。后台页移到窗口外渲染，因为 WebView2 的 IsVisible=false 会忽略输入；菜单、弹窗和卸载期间也移出呈现区域。
- named pipe 使用当前进程 TokenUser SID 的专用 DACL，拒绝远程连接；消息、连接数、诊断条数与响应体均有限额。
- 指针输入逐次验证命中的 frame 和节点，拒绝经主 frame 容器引用点击 iframe；键盘输入逐次验证主 frame 原生控件焦点。当前不支持 contenteditable / 自定义 shadow host 的键盘编辑。

## 默认使用的接入方式

Codex：每个 `app-server` 进程追加 `-c mcp_servers.forge_browser.*`，token 只经进程环境传递。线程 start / resume 前通过 `config/read` 取得项目生效 developer instructions，再追加默认浏览器路由；不替换 baseInstructions。MCP 状态探测收齐分页才广播完整表。

Claude：每个进程追加内联 `--mcp-config`，通过父进程环境继承 token，避免 token 出现在 argv / 配置文件。追加主代理和子代理系统提示，使用 `--system-prompt-snapshot off` 与 `--no-chrome`。生产运行保留用户其他 MCP，不使用 strict 模式；验证程序单独使用 strict 和禁用 hooks，避免调用无关服务。

这让 Forge 成为默认工具选择，但不是模型行为的绝对保证，也没有禁止用户已配置的其他浏览器 MCP。当前没有给“独占所有浏览器工具”打已完成标记。

## 元素选取与问题投递补齐

根因：原生浏览器只有导航和调试控件，没有把引擎选取事件接到现有 AI 草稿输入桥。新增 `picker.rs` 管理 Overlay 生命周期，工具栏提供“选取元素”，元素标记卡提供问题输入和“添加到对话框”。使用页面 ID 和文档代际隔离结果，不给网页增加 Tauri IPC，不改变 AI 的截图或任意脚本授权。

当前一次标记一个元素。标记在取消重选、打开备注、切换侧栏及调整设备布局后保留；选中另一个元素后替换，成功加入当前对话框后清除，也可手动清除。导航到新文档、关闭页面或禁用浏览器时失效。浏览器设置提供“代码”“截图”“截图 + 代码”，默认“截图 + 代码”，偏好跨启动保存且不改变额外权限。代码包含 URL、selector、标签、文字、尺寸和有限计算样式；截图裁剪选中元素当前可见区域，先隐藏高亮再截图并恢复，失败时保留标记与问题。仅截图模式仍附用户问题和页面 URL，不带选择器或样式。图片与文字通过一次输入桥投递，图片上限或写入失败不会先追加问题；清理按选取 ID 校验，旧投递不能清掉新标记。支持主页面元素，不提供 iframe 内部选取、截图批注或多元素编号管理。添加到对话框会追加草稿并聚焦，不自动调用模型。

固定高亮消失的根因是 WebView2 的 `Overlay.setInspectMode` 在 `mode=none` 时仍要求 `highlightConfig`；此前异步选取路径缺少参数并忽略错误，引擎继续跟随鼠标高亮。所有退出路径现在共用完整参数，选取完成后显示引擎错误，侧栏尺寸和设备变化后重新定位固定高亮。

本次三轮审查依次修正：取消重选误删标记、旧交付清理新元素及图片文字分开交付；退出选取遗漏 WebView2 参数和忽略错误；滚动后视口／文档坐标混用。原生回归覆盖鼠标离开后的正常网页点击、取消与 resize 后保留、真实区域 PNG、手机缩小预览下的 DPR 3、滚动后截图及旧选取拒绝；既有输入桥与设置测试覆盖三种模式、默认值、持久化、图片失败保留草稿和跨工作区隔离。

## 元素注释浮层（2026-10-28）

参考用户提供的评论条和样式面板：选取后保留蓝色边框与淡色填充，元素附近显示紧凑评论卡，调节按钮展开样式表单。面板显示元素选择器、评论、收起、恢复样式和绿色发送按钮；支持拖动标题栏和 Ctrl+Enter。颜色、背景、透明度、字体、字号、字重、边框、宽高、外边距、内边距和间距可在当前网页预览。预览只改变网页内联样式，不写项目文件；评论和样式差异送入当前对话框后，由用户决定何时让 AI 修改源码。

根因与结构：网页是独立的原生 child WebView，宿主 React 的 z-index 无法覆盖它。注释使用第二个仅加载内置 HTML 的本地 child WebView，原生层管理位置与叠层；网页没有注释 IPC，也不能读取评论。拒绝外部导航、新窗口和下载，CSP 禁止网络访问。本地面板使用独立临时会话配置。截图仍直接来自网页视图，因此不包含注释窗口或宿主空白。

受限样式命令由 Rust 校验属性白名单和长度，再在隔离世界通过固定函数操作当前 backend node；不向 AI 新增任意脚本能力，不改变上传或 evaluate 的手动授权。先验证整批 CSS，再修改。WeakMap 逐属性记录原值和 priority；恢复、显式清理与有效重选恢复原值，发送成功后保留预览。收起评论不清理预览或标记。页面导航使旧选取失效。所有编辑和清理串行并校验选取身份，旧发送结果不能清掉新标记。
