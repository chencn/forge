# 窗口外壳：主工具栏、槽位与状态条

外壳三层：52px 高的主工具栏、中间一条 flex（活动栏 44px 加侧栏工具窗口加编辑区那一列）、
底部一条 `min-height: 26px` 的状态条。列轨道钉死成容器宽度 `minmax(0, 1fr)`，不用 auto。
auto 按 max-content 量，底部工具窗口一宽整条 body 就被顶出窗口。

布局约定：每个元素先按 IDEA 排，IDEA 里没有对应物的才参考 VSCode。编辑器页签栏是 VSCode 那套。
图标资产的出处见 [tool-window-icons.md](tool-window-icons.md)。侧栏里画什么归
[../file-explorer/](../file-explorer/) 与 [../git-commit/](../git-commit/)，底部五块里终端 / 运行 / Git 日志 / 查找
的内容归 [../terminal/](../terminal/)、[../run/](../run/)、[../git-log/](../git-log/)、[../search/](../search/)，
设置页那一页归 [../settings/](../settings/)。

## 主工具栏

最左一格 44px，与活动栏等宽，右边让出 1px 栏框，正对着栏里的图标。开着侧栏时该格是应用标记
（`icon.svg`，18×18）；侧栏一收，标记让位，该格归折叠按钮。

收起侧栏有两个按钮，改的是同一个 `sidebarOpen`：主工具栏的画 `PanelLeft`（17px），侧栏头部的画
`PanelLeftClose`（15px，画的是侧栏往左收拢，不是 ✕）。头部那排动作只在指针进来时才显形，只有收起侧栏的按钮常驻
（细节见 [../file-explorer/](../file-explorer/)）。

折叠按钮平时浮在侧栏那一段的右缘：`.titlebar-sideband` 绝对定位、`left: 44px`、宽度由 `sidebarWidth`
行内跟着侧栏走、`justify-content: flex-end`、`pointer-events: none`（只有按钮自己接指针）。折叠按钮不放进流程，
是因为进了流程就要占一格，拖宽拖窄会把工程、分支芯片一路顶走；浮着才互不干扰。侧栏一收，工程、分支两个芯片不渲染，
只剩折叠按钮搬进标记那一格。冲突的那对按钮不跟着收，因为它平时不出现，只在仓库停在变基 / 合并 / 摘取 / 还原中间时才画
（见 [../git-commit/](../git-commit/)）。那种时候侧栏多半是收着的，一起收掉就没有出口。

中间整条是可拖区（`data-tauri-drag-region`），但只有 `.titlebar-gap`（`flex: 1`、`min-width: 24px`）
和芯片之外的空白才算拖拽区，芯片本身是按钮。芯片 25px 高、`max-width: 260px`、字号 12.5px。主工具栏上的按钮和下拉
都压在同一条 25px 线上（`.icon-button.is-toolbar`、`.run-selector` 最高 240px）。

右段是运行配置下拉加运行 / 重跑 / 停止，紧跟其后是「随处搜索」。工具窗口关着也能跑，按下运行会顺手把 run 面板叫到底部。下拉和运行 / 重跑
在没开工作区、或选中的那条本机跑不了时禁用，停止只跟着有没有在跑（`RunControls`）。细节见 [../run/](../run/)。

「随处搜索」是 `TitleBar` 的 `search` 槽里那颗按钮，字形 `SearchIcon` 17，与运行那一排同一条 25px 线。没开工程时禁用，
悬停提示是「先打开文件夹」那句；弹层开着时它带按下态（`is-on` 加 `aria-pressed`），再点一次收起弹层。入口与键位见
[../search/](../search/)。

`decorations: false`，最小化 / 最大化 / 关闭三个按钮由前端画。每个 44px 宽撑满行高，关闭按钮悬停是 `--accent-red`
底加 `--on-solid` 字。最大化状态读 `isMaximized()` 并在 `onResized` 上重读，图标在 Maximize 和 Minimize 之间换。
纯浏览器跑前端时这些调用会 reject，全部被 catch 掉，界面照常可用。

实心主按钮那档蓝：`--button-solid` 浅色 `#3574f0`、深色 `#548af7`，文字一律白。悬停只降到 0.88 不透明度，
字色钉死白，免得 hover 时字跟着变灰。这档蓝单开一档，是因为 `--accent-blue`（浅色 `#3b82f6`）那档是给浅底加深字的
选中态用的，tokens 里注明它和实心档不是一回事。这档蓝是按 IDEA 的主按钮取的。落点是提交按钮、对话框确定、解决冲突完成。

## 工程芯片

打开文件夹唯一的入口。没开工程时也一样弹最近列表，末尾那一条就是「打开文件夹…」；一条历史都没有
才直接开目录选择器（`ProjectPicker` 的 `pickable`）。开着工程时同样弹最近列表，多一条「关闭文件夹」。
弹层 `minWidth` 280。最近列表最多 8 条、新的在前、重复的挪到最前（`RECENT_CAP`、`withRemembered`，读 `history.json` 的 `recentFolders`）。点当前那条不重开工程。
末尾两项是「打开文件夹…」和「关闭文件夹」。侧栏的空态和空态页都不再摆按钮，开工程这件事只有主工具栏这一处入口。

## 活动栏

一列 44px。按钮 32×32、列内间距 4px、上下 padding 8px。上端两个管侧栏那格的两种内容（资源管理器、提交），
`.rail-spacer`（`flex: 1`）把下端隔开。下端四颗是终端（`SquareTerminal` 18）、运行（`Play` 17）、Git 日志
（`VcsIcon` 18）、通知（lucide `Bell` 18），次序由 `RAIL_BOTTOM` 说。查找没有下端入口：IDEA 没给 Find 工具窗口
留活动栏入口，它是点开正文命中时自己开出来的，这边照做，见 [../search/](../search/)。IDEA 把底部工具窗口的入口
钉在活动栏下端。设置入口不在活动栏，在主工具栏右段（lucide `Settings` 17）。

- 选中态不给彩色竖条，只给中性底色 `--bg-active`，深浅两套都由 tokens 驱动。
- 上端图标再点一次是收起 / 展开侧栏，只有同一个才 toggle；换一个是切内容并展开。
- 提交图标右下角挂未提交改动数：只在 >0 时画，10px 字、pill、`--accent-blue` 底。
- 下端四个按钮点亮等于不是 hidden。待在底部和待在页签栏里都算开着。
- 悬停片刻在按钮右侧 8px 冒一枚气泡报自己的名字（`data-tip` 走 CSS `::after`，延迟 320ms）。延迟是因为指针掠过一整栏时
  不该一路闪。
- 设置只开不关：页签栏里已经有它就跳过去。

## 工具窗口槽位

一块底部工具窗口有三种待法：`hidden` / `docked` / `tabbed`。

底部一次只坐一块，五块轮着坐：`BOTTOM_ORDER` 是终端 / 运行 / Git 日志 / 查找 / 通知。`dockPane` 先把原来 docked 的那块
退回 `hidden`，渲染时只认这个顺序里第一个 docked 的。底部排他，是因为照的就是 IDEA（代码注释「底部一次只见一块」）。
要同时看几块就切到页签栏，`tabbed` 的能并存，页签目录只收 tabbed 的那几块。查找那块只在点开正文命中时被叫出来，
自己不主动开；通知那块从状态条那颗铃铛或活动栏下端打开。

待在底部和待在页签栏里用的是同一个外壳 `paneFrame`，只差 class 与高度，所以切过去切回来看到的动作一模一样。头部两个按钮
分别管位置和存在：「在选项卡中显示 / 放回底部」只换地方，「最小化」只藏界面。位置和存在分开管，是因为收起不该杀掉 shell
和跑着的任务（`termStore` 攒输出、再点开补画，见 [../terminal/](../terminal/)）。

最小化后再点活动栏的对应按钮要回原处：`lastPlace` 记着每块上次待的位置，切到选项卡过就不硬塞回底部。把日志叫到底部时顺手把高度
抬到至少 380px，因为三栏并排太矮就没法看。

## 分隔条

竖的在侧栏右缘：5px 宽、`--border-color` 上色、`col-resize`。横的在底部面板上方：5px 高、平时透明（看得见的那条线
是 `.bottom-panel` 的 `border-top`）、`row-resize`。两条悬停都变 `--accent-blue-bg`。拖动用 pointer capture，范围：

| 拖哪 | 默认 | 下限 | 上限 |
| --- | --- | --- | --- |
| 侧栏宽 | 320 | 180 | `innerWidth - 560` |
| 底部高 | 260 | 120 | `innerHeight - 240` |

上限留 560 / 240 是给剩下的地方留一条还能读的编辑区。窗口本身最小 760×500。这两个值只活在 state 里、不落盘，
重开窗口回默认（`lib/settings.ts` 没有对应字段）。

## 弹层锚点

主工具栏的芯片与头部动作条共用 `Popover` 这一套定位。横向一律从锚点的左边缘往右开
（`left = clamp(rect.left, 8, innerWidth - width - 8)`）。组件注释把这条写死了：锚点待在窄容器里时弹层就盖到旁边的区域上，
不为了留在容器内而挪到锚点左边。这样弹层宽度不受侧栏那点宽度限制，能按内容撑开（宽度取 `max(minWidth, 锚点宽, 面板自然宽)`）。
只有右边缘会出屏时才整块往回收，靠右的几个弹层不会溢出屏幕。`GAP = 4`（贴锚点下沿）、`EDGE = 8`（离视口边）。
竖向放不下且上面放得下才翻到锚点上沿。
默认带一层全屏遮罩：点外面收，代价是遮罩期间底下的区域吃不到点击。悬停展开的读数传 `modal={false}`，遮罩撤掉、
`role` 换成 `tooltip`，收起交给调用方自己的 `mouseleave`（内存明细那一格延后 150ms 收，否则指针穿过 4px 间隙时浮层会闪掉）。

第一次量完还要 `requestAnimationFrame` 再量一次。列表异步到位时面板比第一次测的高，翻转判断若用旧高度会算错。
遮罩 `.menu-overlay` 全屏、点哪都收，Esc 也收。面板 `max-height: min(520px, 100vh - 16px)` 内滚。

## 编辑器页签栏

四类标签共用 `EditorTabs` 这一栏：文档 / 比对 / 切过来的工具窗口 / 设置页（`TabKind`，id 前缀 `doc|` `diff|` `pane|`
`settings`）。四类走同一栏，是因为设置页原来是盖住窗口的弹框，以后再加整页的面板直接往这栏挂。

栏 34px 高、横向滚动。比对标签带 `FileDiff` 图标、文件名斜体。面板标签复用活动栏那组字形、13px。文档标签按文件名取图标，
和资源管理器同一套（`EntryIcon`，13px）。

栏上有哪些标签由 `tabCatalog` 说，排在哪儿由 `tabOrder` 说。新开一个落在上一次活跃那个的右边，而不是统统追加到末尾。
拖动换序是 HTML5 drag：`dragover` 落到别的标签上就实时把拖动中的那个插到它现在的位子。活跃的被关掉就落到剩下的最后一个，
全关完回空态页。

关闭按钮：脏的画小圆点不画 ✕。中键点标签同样关。面板那类的动作叫最小化不叫关闭，因为 shell 和任务还在后台跑。
右键菜单对文档多一条保存（不脏就置灰）。保存平时是 `Ctrl+S`，菜单里留着它，是因为不写出来记不住键位的人只能去猜。
复制路径只给文档和比对。标签少于两个时「关闭其他」置灰。

## 底部状态条

左端那一格只给一件事：「N 个未提交改动」的可点按钮，没有改动时不画。点它打开提交窗口并把焦点丢进说明框，
对应 IDEA 左端那条可点的检查消息。样式：状态条 11.5px 字、`--chrome-bg` 底、项间 14px；那个按钮 20px 高、悬停 `--bg-hover`。

错误不占这一条：`reportError` 把它写成一条 error 级通知，右下角弹气泡（同时最多 3 条，error 停 9 秒、其余 6 秒，
指针停上去不消失），历史按工程存最近 7 天。文案怎么按界面语言拼见 [../localization/](../localization/)。

中段是当前文档的读数（只有选中的是文档标签时才画）：语言名（Monaco 的别名而不是内部 id，`languageLabel`）、行尾大写、
脏标记（琥珀色）、只读标记。图片没有行尾，那一格换成类型名。右端是内存读数 `appMb/totalMbM`，每 5 秒取一次 `sys_memory`：
前者是本应用及其全部后代进程的合计私有工作集（用私有工作集而不是工作集：工作集含共享页，多进程相加会虚高），后者是整机物理内存总量。`totalMb` 为 0 或纯浏览器里没这条命令时不画。
悬停展开明细浮层，一档一行、按占用降序：宿主进程、WebView 渲染进程、其余按可执行文件名归并，多于一台在名称后带 `×N`；
末尾一行是全部进程数与合计。分组全在服务端做——`sys_memory` 走一次 kernel32 进程快照，
按 `ppid` 从自身往外收全部后代，所以 WebView 的渲染进程、语言服务、终端会话以及它们在终端里起的程序都算得进来；
父进程先退出使 `ppid` 链断掉的那棵子树不计（宁可少报也不混进无关进程），私有工作集读不到的进程按 0 计。

改动计数那一格之后是语言服务那一格（`LspStatusBar`）：`Braces` 图标加运行中的会话数，未打开项目或没有任何一项
切换到外部 LSP 档时整格不绘制。会话状态每 3 秒采集一次 `lsp_session_statuses`，且在下一次排程之前先等上一次完成，
慢响应不会并发发送；这份轮询挂在 `useLspConfig` 的 provider 上（`hooks/useLspSessions.ts`），设置页读取的是同一来源；
采集失败时保留上一次结果，整格转灰并说明「状态获取失败」。点开是弹层，一行一条会话（语言名、该服务的进程名、项目根、状态、异常说明），
异常说明整段换行显示并附复制按钮，不再按宽度截断。两个动作：重试清除后端的退避记录后重新对档，停用把该项档位写为 `off`。
动作名称如此选择是因为仅停止进程而配置未变时，下一次对档会按原配置重新启动。该格只反映进程运行状态，不反映索引是否完成，
rust-analyzer 从启动进程到可查询语义之间的阶段不在其显示范围内。只列当前窗口的会话，见 [../../plans/lsp-language-servers/](../../plans/lsp-language-servers/README.md)。

最右是通知那颗 `Bell`（13px），右下角挂未读数：只在 >0 时画，超过 99 写 `99+`，未读里有 error 时角标转红。
点它走的是活动栏下端那颗的同一套位置规则：收着就回上次待的地方，开着就收起。第一次把它叫出来时把未读全标成已读，
底部和页签栏两处都算开着，点亮状态跟着这两处之一。

## 空态快捷键告示

编辑区空着时给的是 IDEA 那张快捷键告示页（`WelcomeScreen`），不是一片空白。这张表不垫白卡也不描边，只有 margin 和
`min-width`。键位跟着当前快捷键方案变：每行读 `chords[keymap]`，当前方案没绑这条命令就整行不画，免得告示页承诺做不到的事。
12 条里「复制行」在默认方案不出现，「替换」在 Eclipse 不出现。顶上三条是搜索那三个入口，键位三套方案共用，
见 [../search/](../search/)。应用名只在还没开工程时才写一遍。

定位钉在 `.main-column` 那一层而不是编辑区：`position: absolute; inset: 0; z-index: 0`。底部面板那层是 `z-index: 1`。
底栏弹起时那一列的高度不变、告示一格都不挪。被底栏盖住的那截宁可看不见，也比让告示跟着缩更稳。

## 窄窗口

`max-width: 1000px` 时只有侧栏工具窗口浮起来（`position: absolute`、`inset: 0 auto 0 44px`、`z-index: 30`、
180ms `slide-in`），活动栏始终贴在左边。

## 已知边界

- WebView2 自带的刷新 / 打印 / 检查在 capture 阶段被整体 `preventDefault`，每个表面只出与自己相关的菜单
  （各套菜单见 [../file-explorer/](../file-explorer/)）。编辑器内部那层由 Monaco 自己画，见 [../code-editor/](../code-editor/)。
- 工具窗口的去处只有两个：底部那条槽和编辑区页签栏。侧栏那一格只有资源管理器与提交两种内容，没有右侧栏槽位。
- 侧栏宽度与底部高度只活在内存里，重开窗口回 320 / 260。

## 错误边界

每块能独立失效的区域外面各包一层 `ErrorBoundary`（`src/components/ErrorBoundary.tsx`），
子树渲染期抛异常时只把这一块换成一句说明加一个「重试」，不牵动整棵界面。

- **分块包，不是只包根**：根上一旦触发就是整页换成错误页，等于把白屏换成了错误页，人还是什么都干不了。
  现在包了三处——侧栏 `panel-body`、编辑区正文（**不含**页签栏，文档崩了标签还在，关掉这一篇就能自愈）、
  底部工具窗口 `bottom-body`（在 `paneFrame` 里，停靠与选项卡两种形态共用）。
- 错误经 `onError` 转给 `reportError`，进右下角通知历史，和别的错误一条通道。
- 只能接**渲染期同步**抛的异常：事件处理器、异步回调里的由各自的 `try/catch` 收，边界管不着。
- 兜底文案中英并排（`crash-notice`），不读 i18n——边界挂在 Provider 外层，Provider 自己崩了它还得能画。
