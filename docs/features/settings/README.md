# Forge 设置系统（简约扁平模式）

## 1. 架构概述

设置页遵循**约定大于配置**：左侧 `settings-nav` 一行列出全部模块，右侧即点即用，所有设置项实时 patch 并持久化到 Tauri 后端 store。没有树形层级、没有搜索、没有面包屑，也不存在路由适配层。

- 导航与模块枚举：`src/components/SettingsPage.tsx` 中的 `MODULES` / `MODULE_LABEL` / `SettingsModule`；
- 真实设置页组件：`src/features/settings/pages/`（按领域分文件）与 `src/components/` 下的既有面板；
- 约定：内容较多的模块（通用/编辑器/Git）把同领域的页面组件按节标题堆叠成一屏滚到底，其余模块直接挂面板。

AI 相关六个模块（AI 助手/归档会话/模型供应商/Skills/MCP/Hooks）受「AI 助手」总开关门控，开关关闭时从导航隐藏；「AI 提交」不受门控。

## 3. 后续裁剪与扩充指引

新增或移除一个模块只需改 `src/components/SettingsPage.tsx`：

1. 在 `SettingsModule` 与 `MODULES` 中增删模块 id；
2. 在 `MODULE_LABEL` 中绑定 i18n 键；
3. 堆叠型模块改 `sections()`，面板型模块改渲染分支；
4. 需要新节标题时在 `src/i18n/lang/zh.ts` 加键，并同步 `en.ts` 与 `zh-TW.ts`。
