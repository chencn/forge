# 目录树与右键菜单

侧栏资源管理器：一棵按需展开的目录树，一句右键菜单，一组作用在整批选中上的键位。
列目录走 `list_directory`，新建、改名、复制、移动、删除都是后端命令，前端只发参数。
磁盘改动怎么驱动这棵树见 `../workspace-watch/`，点开文件给哪种视图见 `../documents-preview/`。

## 列什么、怎么排

排序在后端一次做完：目录优先，同级按名字小写升序，前端不再排。

`list_directory` 把隐藏项照实返回，过滤在树这一层：`visible()` 按两个设置项判断，
`explorer.showHidden` 管隐藏项、默认关，`explorer.showIgnored` 管被 git 忽略的项、默认开。两个都存在 `settings.explorer`，
存盘和读回缺字段时按同一套默认值补。
Windows 的隐藏位读 `GetFileAttributesW` 的 HIDDEN|SYSTEM，类 unix 认文件名以点开头。
显示出来时隐藏项的字色压到 `--text-muted`，选中或激活时回到常规色。被过滤掉的目录连整棵子树一起藏。
这两个开关也管搜索：全局搜索按同一份 `settings.explorer` 在后端扫描层剪枝，见 `../search/`。

单条 stat 失败进 `unreadable` 数组，不影响同一目录其余条目。

## 行与标记

- 行高 25px，行内间距 5px，缩进 `6 + depth * 13`，箭头槽 14px（箭头图标 13px），文件图标 15px。
- 文件行末的单字母由 `changeMark` 给：未跟踪 `U`，冲突 `!`，其余取工作区那一位；工作区是 `M` 才退回索引位。
- 比对键是仓库根拼相对路径，分隔符统一成正斜杠再小写。仓库根与工程根不重合时，标记仍落在正确的行上。
- 目录行不画字母，画子孙聚合出的圆点：含 `M` 记 `M`，否则取最后一个非 `D` 的字母。删除态不向上聚合，文件已
  经不在盘上。

## 缓存与图标

- 展开过的目录才读盘，条目按目录存进 Map。折叠不清缓存，再展开不重新读。
- 读失败的目录另记一份，错误文案画在该目录那一行下面，不占状态条。
- `refreshSignal` 递增时两个 Map 一起作废。留着旧条目会看见已经删掉的文件。
- 「折叠全部」只清 `expanded`，缓存不动；换工作区根目录同样清空 `expanded`。
- 图标是 IDEA 彩色那套。数据约 200KB，单独一个 chunk 懒加载；首屏先用单色 `Folder` / `File` 占位，装入后由
  `useSyncExternalStore` 的订阅整体换成真图标。
- 解析规则对齐 IntelliJ 的 `extension ?: name`：普通文件取最后一个点之后，`.gitignore` 取点之后，完全没有点的
  名字（`Dockerfile`）退回整个文件名。深色主题缺图时回退浅色那份——深色版在它自己那张表里按
  自己的文件名存（`folder.svg` 对应 `folder_dark.svg`），查之前要先这样换算一次。
- 图标只按「名字 + 是不是目录」解析，不绑 `FsEntry`，所以只有路径的变更树和日志文件树画的图标一致。
- 图标数据由 `scripts/make-file-icons.mjs` 生成，不手改。

## 多选

选中集是一份按点击先后排的路径数组，状态提在 App，右键菜单和键位读同一份。最后一条是主行，`targetDirOf` 和
Shift 的锚点都取它。两处必须同一个来源，否则会出现菜单落在 A、粘贴进 B。

- 单击只留这一条。Ctrl 加选或取消。Shift 在可见的行里连选：取锚点和目标点在 `rows` 中的区间，折叠目录的子项
  不在 `rows` 里，选不到。
- 交给 App 之前 `resolve` 按当前 `rows` 把路径换回条目，顺手剔掉此刻不可见的：刚删掉的、父目录刚折叠的。
- 右键落在没选中的行上时，选中集先换成这一条，与 IDEA 一致。落在已选中的行上时整批不动，菜单作用整批。
- 单击文件只在选中集恰好是这一条时开标签页，多选过程中的单击不开。目录单击只做展开 / 折叠。

## 跟着搜索定位

`reveal` 递一条绝对路径进来，树把它摊开、选中并滚到那一行。一趟只往前推一层：目标行露出来就收工，
没露出来就把还没展开的那层祖先摊开，等它的子节点读回来再算一遍。比的是行上的 `deepest`——包链合并后
一行替好几层露面，展开键是链末那层——所以落在链中间的目录也认得出是哪一行。路径统一折成 `/` 连接、
大小写折叠之后才比，Windows 上后端给的两条写法才对得上。这个 effect 不挂依赖数组：`rows` 每次渲染
现算，挂不上，而每一层进展都要重算一次才知道走没走到头。

三条收工的路径：这条路径不在工程根下、被「显示隐藏 / 显示忽略」两个开关挡在外面、祖先都读完了却没有它
（刚删掉）。收工时不改选中集，也不报第二遍错，搜索那边刚从同一张盘上扫出它。

侧栏收着要先打开、停在 Git 面板要扳回资源管理器，这两件都在 App 那侧，见 `../search/`。

## 右键菜单

一份 `requestMenu` 同时管文件行、目录行和树的空白处。空白处传的是空数组，等于没有选中。判据用
`closest('.tree-row')`：落在任何一行上都不管，那一行自己的处理器会带着选中集来；用「target 是不是容器
本身」判会把包链行上的右键也当成空白处，因为行外面还套着 `role=none` 的包装层。

落点由 `targetDirOf` 定：单选一个目录落在它里面，其余落在主行的上一层，没有选中时落在工程根。新建、粘贴和
「在目录中查找」都读这一个口径，后者对应 IDEA 的 `FindInProjectUtil.setDirectoryName`（目录取自身、文件取父目录、
空白处取工程根）。取到的是工程根时不把那个路径传给弹层，作用域就是整个工程，省得写出「在整个工程里再搜一个子目录」。
WebView2 自带的「刷新 / 打印 / 检查」被两道闸挡住：`src-tauri/src/lib.rs` 的 `disable_default_context_menu` 在
启动时从 `ICoreWebView2Settings3` 上关掉它（不依赖页面存活，页面挂了也不会冒出来），`src/App.tsx` 另在 capture 阶段
`preventDefault` 兜一层。应用自己的菜单在事件里摆，不受这两条影响。

| 序 | 项 | 键位 | 门控 |
| --- | --- | --- | --- |
| 1 | 新建文件 / 新建文件夹 | 无 | 总在。默认名 `untitled.txt` 和「新建文件夹」 |
| 2 | 剪切 / 复制 | Ctrl+X / Ctrl+C | 没有选中时置灰出现，不是隐藏 |
| 2 | 粘贴 | Ctrl+V | 只在这一次攒过东西时出现，`clipboard` 为空时不摆这一项 |
| 3 | 打开 | 无 | 只给单选的文件 |
| 4 | 重命名 / 删除 | F2 / Delete | 重命名要求恰好一项，多选置灰并给悬停提示「一次只针对一项做」；删除是告警色，作用整批 |
| 5 | 复制路径 | 无 | 整批一次复制，绝对路径按 `\n` 连接 |
| 5 | 在系统文件管理器中打开 / 用关联应用打开 | 无 | 都只在恰好一项时出现；后者只给文件 |
| 6 | Git 子菜单 | 无 | 有仓库且这批里有文件才出现：暂存作用整批文件，历史记录只给单选且已跟踪的那个文件（未跟踪的没有来路可查，摆出来就是一条空的记录），忽略文件作用整批 |
| 7 | 在目录中查找 | 无 | 开了工程才出现，紧跟 Git 组单独一组。作用层按上面那条口径取，点开的是随处搜索的文本页签，词取编辑器选区，见 [../search/](../search/) |
| 8 | 比较文件 | 无 | 恰好两个文件。读磁盘上这两份现在的文本，编辑器里未保存的改动不参与 |
| 9 | 刷新 | 无 | 树重读加 git 状态重取 |

IDEA 那份菜单里后端不支持的项不摆出来（查找用法、替换、标记源根、本地历史），而不是灰着列在菜单里。

## 键位

菜单上画了键位的项必须真能用。Ctrl+X / Ctrl+C / Ctrl+V、F2、Delete 只在侧栏开着、当前面板是资源管理器、且有
选中时接手；焦点在输入框、文本域、contenteditable 或编辑器里一律让行。Ctrl 组合遇到 Alt 或 Meta 一起按时不接管，
那两套键属于提交面板的分组依据。F2 只认单选，Delete 作用整批。

## 写盘动作

- 粘贴撞名不覆盖，后端的 `TARGET_EXISTS` 原样报回界面，换名由人决定。覆盖之后找不回来，这里不猜。
- 剪切后贴回它自己所在的目录时整条跳过。剪切那批贴完即清空 `clipboard`；真的挪动过条目时连选中集一起清空，那
  几条已经在别处，留着会让下一次删除或粘贴落在已经不存在的旧路径上。攒下的批只在 React state 里，不落盘。
- 同盘挪动是一次 rename。跨盘时整份复制完再删源，删不掉就报 `MOVED_WITH_SOURCE`，把复制到的目标和没删掉的源
  两条路径一起说清楚。
- 复制目录连内容一起递归。
- 重命名只在原目录里换名字，目标已存在同样报 `TARGET_EXISTS`。成功后旧路径的文档一起关掉，有未保存改动的不关。
  对话框默认只选中主名，扩展名不动。
- 删除是永久删除，目录走 `remove_dir_all`，不进回收站。确认框按文件、目录、多条挑文案，多条那句带「等 {count}
  项」和「此操作无法撤销」。删完清选中、关掉对应文档、重读树。
- 「忽略文件」往 `.gitignore` 末尾追加仓库相对路径（正斜杠），已写过的行不重复，仓库里没有这个文件就从空写起。

## 侧栏头部与菜单浮层

- 头部的四个动作（新建文件、新建文件夹、折叠全部、刷新）平时 `opacity: 0` 加 `pointer-events: none`，指针进入
  头部或键盘 `:focus-visible` 时显形。位置一直占着，出来进去不改变行高。收起侧栏的按钮常驻，否则指针没进入这一
  行时找不到出口。
- 头部的两个新建落点固定是工程根，与菜单里的落点规则不同。
- 菜单条目 34px 高，分隔线 9px，`min-width` 220px，离视口边 8px。定位先用实测盒子，量不到时按 244px 宽和条目
  累加的高度估。
- 分组由 `flatMenu` 摊平：空组丢掉，分隔线只加在组之间。
- 子层起点是父项的 `right - 4` / `top - 6`。指针离开后 220ms 宽限期才收，跨过两层之间那条缝时子层不会被判成已
  离开。点开子层时父层不关，选中末端的动作才整条关掉。
- Esc、遮罩上的单击和遮罩上的右键都关闭菜单。
